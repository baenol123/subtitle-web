자막 번역, 비용과 시간을 얼마나 아낄 수 있을까

2026년 7월 31일 · 자막공장 가이드

1시간 분량 영상 자막을 번역해야 한다면 방법에 따라 비용과 소요 시간이 크게 갈립니다. 세 가지 선택지를 실제 감각으로 비교해봅니다.

외주 번역

전문 번역가에게 맡기면 뉘앙스와 고유명사 처리가 가장 정교하지만, 1시간 분량 기준으로 작업 기간이 며칠에서 1~2주가 걸리고 비용도 상당합니다. 상업적으로 배포하는 콘텐츠나 품질이 최우선인 프로젝트가 아니라면 개인이 감당하기엔 부담스러운 경우가 많습니다.

유료 AI API (Claude, GPT 등)

AI 모델의 API를 직접 호출해 번역하면 사람보다 훨씬 빠르고(보통 몇 분 내), 비용도 외주보다 훨씬 저렴합니다. 1시간 분량 자막(약 600~800줄) 기준으로 저가형 모델을 쓰면 몇백 원 수준에서 처리되는 경우가 많습니다. 품질도 최신 모델은 상당히 자연스러운 편이라, 개인 프로젝트에 가장 현실적인 절충안입니다.

무료 AI 도구

Google Gemini처럼 무료 API 티어를 제공하는 모델을 쓰면 비용 없이도 번역이 가능합니다. 다만 무료 티어는 하루 요청 횟수 제한이 있어, 많은 파일을 한꺼번에 처리하려면 이 한도에 걸릴 수 있습니다. 요청을 최대한 묶어서 보내는 방식으로 한도 소모를 줄이는 게 관건입니다.

실제로는 무엇을 골라야 할까

  • 가끔, 개인적으로 보는 용도 → 무료 AI 도구로 충분합니다.
  • 정기적으로, 여러 편을 처리한다 → 저가형 유료 API가 무료 한도 관리 스트레스 없이 안정적입니다.
  • 배포·판매용 콘텐츠 → AI로 초벌 번역을 만든 뒤 사람이 검수하는 방식이 비용 대비 품질이 가장 좋습니다.

직접 비교해 보고 싶다면

자막공장은 무료 Gemini와 유료 Claude 모델을 모두 지원해서, 같은 파일을 두 방식으로 번역해보고 품질과 속도를 직접 비교할 수 있습니다. 용어집·교정 치환으로 결과를 다듬으면 저가형 모델로도 품질 격차를 상당히 줄일 수 있습니다.
